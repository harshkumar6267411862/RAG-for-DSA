# Conversational RAG Question Answering System

A **Retrieval-Augmented Generation (RAG) conversational AI system** that answers questions using information retrieved from documents.

This project integrates:

- **LangChain**
- **ChromaDB (Vector Database)**
- **Hugging Face Transformers**
- **Sentence Transformers**
- **Flask Backend**
- **ChatGPT-style Web UI**

The system retrieves relevant document chunks and generates grounded answers using a local language model.

---

# 🚀 What is RAG?

RAG (**Retrieval-Augmented Generation**) combines two AI capabilities:

### 1️⃣ Retrieval
Search for relevant documents from a knowledge base using vector similarity.

### 2️⃣ Generation
A language model generates an answer using the retrieved documents.

```
User Question
      ↓
Vector Search (ChromaDB)
      ↓
Relevant Document Chunks
      ↓
LLM Generates Answer
      ↓
Final Response
```

This approach **reduces hallucinations** and produces **fact-based responses**.

---

# 🧠 Features Implemented

## Conversational RAG
The system maintains chat history and rewrites follow-up questions into standalone queries for better retrieval.

Example:

```
User: What is an array?
User: What is its time complexity?
```

The system rewrites it internally to:

```
"What is the time complexity of arrays?"
```

---

## Vector Search

Documents are stored in **ChromaDB** using embeddings generated by:

```
sentence-transformers/all-MiniLM-L6-v2
```

The retriever returns the **top 5 most relevant chunks**.

---

## Local Language Model

Instead of using paid APIs, the project runs a **local Hugging Face model**:

```
google/flan-t5-small
```

This allows the system to run completely offline.

---

## ChatGPT-Style Web Interface

A simple frontend was built using:

- HTML
- CSS
- JavaScript

Features include:

- Chat interface
- Message bubbles
- Typing indicator
- Chat history loading
- New chat reset button

---

## Flask API Backend

The backend exposes endpoints used by the frontend.

```
/chat       → send question
/history    → load conversation
/reset      → clear chat
```

# 🧪 Create Virtual Environment (venv)

A **virtual environment isolates project dependencies** so they do not conflict with other Python projects.

### Create virtual environment

```
python -m venv venv
```

### Activate the virtual environment

Windows

```
venv\Scripts\activate
```

Mac / Linux

```
source venv/bin/activate
```

After activation you should see:

```
(venv)
```

in your terminal.

# ❗ Challenges Faced

## Dependency Conflicts
Managing compatibility between **LangChain and Transformers versions**.

## Model Compatibility
Adjusting pipelines to work with **Transformers v5 changes**.

## Chat History Management
Synchronizing frontend UI with backend conversation memory.

## Local Model Performance
Running models efficiently on CPU required choosing smaller models like:

```
flan-t5-small
```
